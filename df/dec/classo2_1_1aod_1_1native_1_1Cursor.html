Detailed Description

Bounds-checked big-endian reader over a buffer. Every read past the end raises CorruptData, so malformed input can never cause an out-of-bounds read. fileOffset is where the buffer starts in the file, used in error messages. origin is added to positions to get ROOT's buffer displacement, which is what object references are keyed on (fKeylen for an object read from a key).
