Detailed Description

TG4RunConfiguration that appends O2MonopolePhysics to the composed physics list which VMC builds for the requested reference list. Derives from o2::g4config::G4RunConfiguration (rather than TG4RunConfiguration directly) so that monopole runs keep the G4 fast-simulation hook and the local magnetic fields
