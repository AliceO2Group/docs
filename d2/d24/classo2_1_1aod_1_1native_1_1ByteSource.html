Detailed Description

Random access to the bytes of a file. Everything above this is I/O-agnostic. The caller always owns the destination. Implementations are thread-safe for concurrent reads.

Opens the first replica which opens, and on a read error retries it (Options::readRetries times, reopened) and then moves on to the next replica of the same size. log, if given, is told about every retry and every change of replica. Throws IoError when no replica is left.
