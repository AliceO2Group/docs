Detailed Description

Decompresses the chunks of a ROOT compressed payload incrementally into caller-provided memory. Each read() continues where the previous one stopped, so a caller can stop at the end of the value region without producing (or holding) the rest. Only LZ4 needs scratch memory, and only when a read ends in the middle of an LZ4 chunk.
