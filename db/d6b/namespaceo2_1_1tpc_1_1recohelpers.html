TPC row and sector-edge accounting

These helpers evaluate the first outward TPC trajectory branch at sampled Mapper row radii and classify every accepted crossed row using the physical active-pad edge plus an optional inward guard.

Apply acceptance and classify one crossed row as Dead, Excluded, or Available.

The physical active-pad edge is N_pads(row) * padWidth / 2 in sector-local y. A point outside that edge is Dead. Otherwise the side-dependent guard is measured inward from that edge; points inside the guard are Excluded and the remaining crossed rows are Available.

This function updates row counts, approximate lengths, row masks, and first/last Dead row consistently.

Conservative path-continuity guard against a later outward orbit.

This is a gross-branch-rejection criterion, NOT an H/K numerical-agreement tolerance. The generous factor 10 avoids flagging near-boundary valid segments; a long detour around a curl cannot be accepted merely because its final radial direction is outward.

K row evaluator: O2 Propagator traversal of TPC row radii without material correction.

The first eligible row is initialized from analytic H propagation of the supplied complete TrackPar, after which the O2 Propagator advances the track row by row with MatCorrType::USEMatCorrNONE. The radial-frame maxSnp stop and common row classification are applied independently of the Propagator's rotating internal tracking frame. Numerical propagation failures return PropagationFailed; a physical snp stop returns OK with the last accepted row reported in maxRadiusCm.

The O2 magnetic field must already be initialized; otherwise FieldNotInitialized is returned.

L row evaluator: stack-local linear approximation to the analytic helix.

Rows with equal Mapper pad height are treated as one stack. Analytic H endpoints define linear interpolation in phi and z versus radius. If the nominal outer endpoint is unreachable or reaches maxSnp first, the last reachable row below maxSnp becomes the endpoint of a retained partial stack and the outward traversal stops after that stack. Row position, momentum direction, and ds/dr are then evaluated from the local approximation before classification.
