Detailed Description

Lightweight O2 track-geometry helpers for propagation to cylindrical radii and TPC row/sector-edge accounting.

The header provides two related layers:

  1. o2::recohelpers
    • propagation of an o2::track::TrackPar to a cylindrical radius;
    • H: fast analytic helix transport in a uniform Bz field;
    • K0: O2 TrackPar parameter propagation in Bz, without material correction;
    • derived global position/momentum, position azimuth, momentum azimuth, tan(lambda), and fractional sector position;
    • scalar and batch interfaces for primary-like and local O2 track parameters.
  2. o2::tpc::recohelpers
    • TPC row sampling geometry from o2::tpc::Mapper (F6 centre correction pending);
    • H: analytic-helix row traversal;
    • L: stack-local linear approximation derived from helix endpoints;
    • K: O2 Propagator row traversal with MatCorrType::USEMatCorrNONE;
    • row counts, approximate track lengths, and 152-row masks for Crossed, Dead, Excluded, and Available rows;
    • configurable longitudinal, local-inclination, and active-pad-edge guard acceptance.

The TPC classification currently samples the Mapper's inner-row reference radius (F6: pad-centre correction pending). Dead is defined by the physical Mapper active-pad boundary, while Excluded is the additional configurable guard measured inward from that active-pad edge. The nominal 20-degree sector boundary is not the guard reference.

This header is intentionally self-contained and header-only so the same definitions can be used from compiled O2 code and from PyROOT/commissioning wrappers.

Propagation hierarchy and implementation status

The frozen TrackGeometry design distinguishes the following transport levels:

  • H — analytic helix, constant signed Bz, no material. Implemented for the generic state-at-radius API and for TPC row traversal.
  • L — stack-local linear approximation. Implemented for the TPC row/length approximation path only.
  • K0 — O2 TrackPar / TrackParametrization, constant signed Bz, no material. Implemented for the generic state-at-radius API.
  • K1 — O2 Propagator, initialized O2 magnetic-field machinery, material OFF. The current TPC row evaluator named K already uses Propagator with MatCorrType::USEMatCorrNONE and therefore exercises the K1 transport ingredients for this bounded TPC-row use case. The common generic K0/K1/K2 state-at-radius dispatch and final public K1 naming are not yet implemented.
  • K2 — O2 Propagator, initialized O2 magnetic-field machinery, material ON. Not yet implemented. The production material mode and material-map initialization must be explicitly verified during K2 commissioning before this mode is exposed.

The intended diagnostic decomposition is: H-K0 = implementation/convention closure, K1-K0 = realistic-field/Propagator effect, K2-K1 = material effect.

Planned functionality is documented here deliberately so that the public contract is visible before implementation; planned modes must not be presented by wrappers as available until the corresponding C++ path and validation exist.
