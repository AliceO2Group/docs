H transport: analytic helix intersection with a cylindrical radius in uniform Bz.

The implementation solves the transverse circle/circle intersection analytically, selects the first solution compatible with the requested direction, and transports z with the constant input tan(lambda). Double precision is used internally for the geometric construction, while the public state remains float.

Parameters
trackInput O2 track parameters.
radiusTarget cylindrical radius [cm].
bzKGUniform Bz field in O2 kG convention.
dirRequired radial propagation direction.
Returns
Global state and status at the requested radius.

K0 transport: O2 TrackPar propagation to a cylindrical radius in Bz, without material correction.

getXatLabR() locates the local-x target corresponding to the requested laboratory radius and propagateParamTo() performs the O2 parameter transport. A state is reported as OK only when its final global radius agrees with the requested cylinder within 2e-3 cm; an off-radius one-step result is PropagationFailed. This path is used as an independent O2 transport reference for the fast analytic H implementation.

Parameters
trackInput O2 track parameters.
radiusTarget cylindrical radius [cm].
bzKGBz field in O2 kG convention.
dirRequired radial propagation direction.
Returns
Global state and status at the requested radius.
