Detailed Description

One signed implicit halfspace, the region sign * f(x) <= 0: kQuadric stores x^T A x + 2 b^T x + c as (a00, a01, a02, a11, a12, a22, b0, b1, b2, c); kTorus stores (px, py, pz, dx, dy, dz, R, r) in the first eight.
