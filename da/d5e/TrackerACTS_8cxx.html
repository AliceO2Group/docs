Detailed Description

TRK tracker using ACTS seeding and track finding.

Author
Nicolò Jacazio, Università del Piemonte Orientale (IT)
Since
2026-04-01

The tracker processes one readout frame (ROF) at a time. For each ROF it maps clusters to ACTS surfaces, creates ACTS space-point triplet seeds, fits each seed with the ACTS Kalman fitter, and publishes accepted tracks in the O2 TimeFrame. Optional ROOT and JSON output records intermediate information for diagnostics; neither output is required for reconstruction.

ACTS geometry is supplied by the process-wide o2::acts::TrackingGeometryManager. Before its first build, the workflow must make the aligned O2 TGeo geometry available and install the detector-specific ACTS geometry builder. The manager builds the geometry lazily and keeps it immutable; surface pointers stored in space points are non-owning references to that manager-owned geometry.

Cluster coordinates from the TimeFrame are in cm and are converted to ACTS mm when space points are created. ACTS contexts, local coordinates, field values, and fit parameters must therefore use ACTS units. Conversion back to the O2 track representation is performed only when a track is accepted.
