◆ kAutoBufferBudget

constexpr size_t o2::aod::native::Options::kAutoBufferBudget = SIZE_MAX
staticconstexpr

Most bytes the read plans of a file hold at once, 0 for no limit. A DF larger than this is read in groups of trees. kAutoBufferBudget: 16 MB for a local file, 64 MB for a remote one, where each read is a round trip.

size_t o2::aod::native::Options::remoteInFlightBytes = 32 * 1024 * 1024
